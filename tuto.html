Installation

Installez seulement les extensions dont vous avez besoin : le raccourci les télécharge toutes, vous choisissez lesquelles charger dans votre navigateur à l’étape 5. Vous utilisez Chrome et Arc ? Faites les étapes 4 à 6 dans les deux.

  1. Ajouter le raccourci

    Ouvrez le lien du raccourci « Extensions MPG » sur votre Mac. L’app Raccourcis s’ouvre : cliquez Ajouter le raccourci.

  3. Lancer le raccourci

    Double-cliquez sur Extensions MPG dans l’app Raccourcis. La première fois, macOS demande si Raccourcis peut contrôler Google Chrome (et Arc s’il est installé) : cliquez Autoriser (ou OK).

    Le raccourci crée le dossier Extensions MPG dans votre dossier personnel, l’ouvre dans le Finder, et ouvre la page Extensions de Chrome et d’Arc.

    Ne déplacez pas et ne renommez pas ce dossier : Chrome et Arc chargent les extensions directement depuis là.

  5. Charger chaque extension

    • Cliquez Charger l’extension non empaquetée.
    • Faites ⌘ ⇧ G, puis ⌘ V (le raccourci a copié le chemin du dossier) et Entrée.
    • Sélectionnez le dossier d’une extension, par exemple Ligues de test, puis Sélectionner.

    Recommencez pour chaque extension voulue. Chacune apparaît alors dans la page, avec son interrupteur activé.

En cas de souci

« L’exécution de scripts n’est pas autorisée »

Refaites l’étape 2 : Raccourcis › Réglages › Avancé › Autoriser l’exécution des scripts.

Le navigateur ne s’est pas ouvert sur la page Extensions

Tapez chrome://extensions (Chrome) ou arc://extensions (Arc) dans la barre d’adresse. Si vous avez cliqué « Ne pas autoriser » à l’étape 3, ce n’est pas grave : tout le reste est installé. Pour changer d’avis : Réglages Système › Confidentialité et sécurité › Automatisation.

« Problèmes : téléchargement impossible »

Vérifiez votre connexion internet et relancez le raccourci. Si le message reste, prévenez Frank : l’extension n’est peut-être pas encore publiée.

Une extension s’appelle « À supprimer – remplacée par … »

L’extension a été renommée. Supprimez celle marquée « À supprimer » sur la page Extensions (et son ancien dossier dans Extensions MPG), puis chargez le nouveau dossier (étape 5). Ses réglages et historiques repartent de zéro.

Une extension affiche une erreur ou a disparu du navigateur

Le dossier Extensions MPG a sans doute été déplacé, renommé ou supprimé. Relancez le raccourci, puis rechargez l’extension (étape 5) si elle n’est plus dans la liste.

Chrome propose de désactiver les extensions en mode développeur

Refusez (fermez le message) : sinon les extensions MPG sont désactivées.

Les outils ne marchent pas sur une page déjà ouverte

Rechargez la page (⌘ R). Après une installation ou une mise à jour, les onglets ouverts avant gardent l’ancienne version.
